# 📚 MyBooks – Bibliotheksverwaltung

Ein Abschlussprojekt im Rahmen der JavaScript-Weiterbildung.

## 📌 Projektbeschreibung

**MyBooks** ist eine einfache Webanwendung zur Verwaltung von Büchern in einer kleinen Bibliothek.  
Benutzer können sich anmelden, Bücher hinzufügen, bearbeiten oder löschen und den Status von Büchern aktualisieren (z. B. *verfügbar*, *ausgeliehen*, *reserviert*).

## 🗂 Projektstruktur

Die Anwendung ist in drei Hauptbereiche gegliedert:

- **`public/`**  
  Frontend-Dateien (HTML, CSS, JavaScript):  
  Enthält z. B. `login.html`, `books.html`, `login.js`, `books.js` usw.

- **`routes/`**  
  Enthält die Routing-Logik für HTTP-Anfragen, z. B. `auth.js`, `books.js`.

- **`controllers/`**  
  Beinhaltet die Geschäftslogik und Anbindung an die Datenbank (z. B. `authController.js`, `booksController.js`).

## 🛠️ Verwendete Technologien

### Backend
- Node.js
- Express.js
- CouchDB
- Nano (CouchDB-Client für Node.js)

### Frontend
- HTML
- CSS
- JavaScript (ES6)
